# Skyline Rush

Endless runner made in Godot 4.3. The project is in [`skyline_rush/`](skyline_rush/). Open `skyline_rush/project.godot` in Godot 4.3+ and press F5.

`skyline_rush_v7.zip` is the same project packaged for download. See [`skyline_rush/README.md`](skyline_rush/README.md) for controls, maps, vehicles and upgrades.
