# Skyline Rush

Endless runner made in Godot 4.3 by Chaos Games. The project is in [`skyline_rush/`](skyline_rush/). Open `skyline_rush/project.godot` in Godot 4.3+ and press F5.

## Downloads (v9)
| File | What it is |
|---|---|
| `SkylineRush_v9_Windows.zip` | **Windows game.** Unzip and double-click `SkylineRush.exe`. No Godot needed. Fullscreen at native resolution, with AO and real-time GI. Model textures are 2048 px so the download fits in one file; the project zip keeps the full 4096 px. |
| `SkylineRush_v9_Android.apk` | **Android game** (arm64, Android 7+). Copy it to your phone, open it and allow "install unknown apps". Touch controls, Mobile renderer, no GI. |
| `skyline_rush_v9.zip` | The complete Godot project (source, models, music, tools). |

See [`skyline_rush/README.md`](skyline_rush/README.md) for controls, maps, vehicles, upgrades and what's new.
