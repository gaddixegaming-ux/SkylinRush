# Skyline Rush 12.1 - Android test build

Direct downloads (open on the phone or tablet, then tap the file to install):

- **Most phones and tablets (64-bit):** [SkylineRush-TEST-arm64.apk](https://github.com/gaddixegaming-ux/skylinrush/raw/android-test-build/SkylineRush-TEST-arm64.apk)
- **Older devices (32-bit, e.g. older Amazon Fire tablets):** [SkylineRush-TEST-arm32.apk](https://github.com/gaddixegaming-ux/skylinrush/raw/android-test-build/SkylineRush-TEST-arm32.apk)

Android 7.0 or newer. If Android asks, allow installs from your browser, then tap Install.
If the 64-bit file says "App not installed", use the 32-bit one.

This is a test build: ads are 3-second stand-ins and diamond packs are free test
purchases. It installs as a separate app ("Skyline Rush TEST"), not over the
Play Store version.
